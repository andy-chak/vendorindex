# VendorIndex — published data & site

The **generated, public output** of VendorIndex: the built static website and
machine-readable JSON data. Produced from a private source repo; this repo is the
public audit trail — every published number traces to a commit.

- **Live site:** https://vendorindex.dev
- **Machine-readable data:** `data/categories/<category>.json`, `data/vendors/<vendor>.json`
- **What it is:** neutral, verified comparisons of the vendors coding agents pick — current
  pricing, per-use-case scores, agent-friction, and analytics/data-access attributes.

Do not edit by hand — this repo is overwritten on each publish. Data licensed CC BY 4.0.
